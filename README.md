# Інтелектуальний аналіз та візуалізація даних

Лабораторні роботи. Савков Олександр, група ШІ-33, НУ «Львівська політехніка».

## Склад

| Тека | Робота | Вміст |
|---|---|---|
| `lab1/` | Лабораторна №1 — очищення та розвідувальний аналіз даних | ноутбук, вихідні дані |
| `lab2/` | Лабораторна №2 — оптимізаційна модель та аналіз чутливості | ноутбук, модель Excel |
| `lab3/` | Лабораторна №3 — діагностика шкал вимірювання | ноутбук, вихідні дані |

## Лабораторна №1

`lab1/ЛР1_Савков_Олександр.ipynb` — повний конвеєр: завантаження, перевірка пропусків і викидів,
агрегація по годинах, візуалізації, висновки.

Дані в `lab1/data/`: `20171129_FINAL_FINAL.xlsx` — вихідний файл з ВНС, `master_hourly.csv` —
погодинна зведена таблиця, отримана в ноутбуці.

## Лабораторна №2

`lab2/ЛР2_Савков_Олександр.ipynb` — варіант 6, «Longer Boats»: побудова моделі лінійного
програмування, розв'язання через `scipy.optimize.linprog`, тіньові ціни, зведені вартості та межі
зміни правих частин обмежень.

`lab2/data/ЛР2_модель_Савков.xlsx` — та сама модель для надбудови «Пошук рішення» у Excel:
аркуш моделі з формулами, звіт про стійкість і параметри запуску.

## Лабораторна №3

`lab3/ЛР3_Савков_Олександр.ipynb` — варіант 6: паспорт восьми змінних із обґрунтуванням шкали,
допустимі статистики за шкалою, безглузді числа в `describe()`, міра зв'язку для пари
`Ліжко днів` × `Вік`, підготовка стовпців до моделі та виправлення десяти помилок у чужому звіті.

Дані в `lab3/`, поруч із ноутбуком: `Ковід_дані_навчальні.xlsx` — журнал ковідного відділення
з ВНС, 121 пацієнт і 77 ознак; `lr3_variants_student.json` — таблиця варіантів, з якої
клітинка видачі бере набір стовпців за номером у списку.

## Запуск

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install numpy pandas scipy matplotlib seaborn openpyxl jupyter
jupyter lab
```

Ноутбуки виконуються повністю через Restart & Run All; шляхи до даних відносні, тому запускати
треба з теки відповідної лабораторної.
